# sky.hachile.org

Skyblue Mornbreeze 的小马身份导航页。滚轮缩放，拖动地图，点击云中城阅读个人简介，点击探险丛林前往 Bronymap。[桌面地图](https://sky.hachile.org/)和[手机版旅行指南](https://sky.hachile.org/m/)均提供中、英文。

地图以 `background.png` 为底图。瀑布、火山烟、云、帆船和列车单独绘制在场景层上。桌面地图响应系统的“减少动态效果”设置。

纯静态 HTML/CSS/JavaScript，无构建依赖。

```powershell
node --test
python -m http.server 4173
```

地图原画见 [Derpibooru #1067179](https://derpibooru.org/images/1067179)。第三方插画、字体和音乐的权利归各自权利人。详见[许可说明](LICENSE)。
